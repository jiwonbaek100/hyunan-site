성공사례와 인사이트를 직접 발행합니다.

글 제목, 요약, 분야, 대표 이미지, 본문 이미지를 관리자 편집기에서 입력하면 저장 후 자동으로 hyunan.kr의 인사이트 목록과 홈페이지 최신 글에 반영됩니다.

관리자 편집기 열기 발행 목록 확인

발행 순서

1
GitHub로 로그인Pages CMS에서 jiwonbaek100/hyunan-site 저장소를 선택합니다.
2
인사이트·성공사례 선택새 글을 만들고 제목, 요약, 발행일, 글 유형, 업무분야를 입력합니다.
3
사진 업로드대표 이미지와 본문 이미지는 편집기에서 올리면 images/uploads에 저장됩니다.
4
공개 후 저장공개를 켠 뒤 저장하면 GitHub Pages 배포 후 사이트에 반영됩니다.
글 유형

성공사례, 법률정보, 현안소식 중 하나를 선택합니다. 성공사례는 실제 처리한 사건만 올립니다.

사진

판결문, 의견서, 후기 캡처는 이름, 사건번호, 연락처, 계좌 등 식별정보를 지운 뒤 업로드합니다.

반영 시간

저장 직후 바로 보이지 않을 수 있습니다. 보통 1~3분 뒤 새 글이 목록 상단에 나타납니다.

처음 사용할 때는 Pages CMS GitHub 앱의 저장소 접근 승인이 필요합니다. 이 사이트는 정적 사이트라 hyunan.kr 자체에 비밀번호를 저장하지 않고, GitHub 권한으로 글과 이미지를 안전하게 저장합니다.
